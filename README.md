# 💻 Aula 2 — Front-end e Back-end

Projeto desenvolvido durante as aulas da graduação em Ciência da Computação com o objetivo de praticar conceitos iniciais de desenvolvimento web.

O repositório reúne projetos e exercícios desenvolvidos durante a disciplina, permitindo acompanhar minha evolução nos primeiros contatos com desenvolvimento de aplicações web.

## 🎯 Objetivo

Praticar a estruturação de projetos web e compreender como diferentes partes de uma aplicação podem ser organizadas em um mesmo projeto.

## 🛠️ Tecnologias

* HTML5
  

> Novas tecnologias serão adicionadas ao projeto conforme avanço na graduação.

## 📂 Projetos incluídos

### 🍲 Sabores da Casa

Projeto voltado à criação de uma interface web relacionada ao segmento de alimentação.

**Principais objetivos:**

* Estruturar páginas utilizando HTML;
* Criar navegação entre páginas;
* Organizar conteúdo e elementos visuais;
* Aplicar estilos utilizando CSS.

### 🏋️ TechFit

Projeto acadêmico voltado à criação de uma interface web relacionada ao segmento fitness.

**Principais objetivos:**

* Estruturação de páginas;
* Organização de conteúdo;
* Navegação;
* Aplicação de estilos;
* Prática de desenvolvimento front-end.

## 📚 Conceitos praticados

* Estruturação HTML
* Semântica básica
* Organização de arquivos
* Navegação entre páginas
* Construção de interfaces
* Estruturação de pequenos projetos web

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Danhiyaro/Aula-2-Front-e-Back-end.git
```

2. Acesse a pasta do projeto.

3. Entre na pasta do projeto que deseja visualizar.

4. Abra o arquivo HTML principal em seu navegador.
